## 🐛 Quick Fixes

| Issue | Fix |
|-------|-----|
| Port 8000 busy | `taskkill /F /IM python.exe` |
| Port 3000 busy | `taskkill /F /IM node.exe` |
| No products showing | Restart backend |
| "Request Failed" | Check http://localhost:8000/health |
| Need new npm install | `cd frontend && npm install --legacy-peer-deps` |
